# Chipr League Microsite

Empowering Sales Excellence with Year-Round Rewards and Career Growth - A dynamic platform that transforms sales achievements into epic competitive seasons.

## Description

Chipr League is a comprehensive sales rewards program that celebrates excellence through quarterly competitions and year-round recognition. Through the Champions Club and seasonal challenges, we create an engaging environment where sales professionals can showcase their achievements, earn rewards, and build lasting careers.

## Features & Pages

- **Season in Spotlight**: Current quarter's featured competition and achievements
- **Epic Seasons**: Historical seasons and past champions showcase
- **Champions Club**: Elite tier recognition and exclusive benefits
- **League Swag**: Rewards catalog and merchandise collection
- **The Forge**: Training resources and career development tools
- **FAQs**: Program guidelines and support information

## Technical Stack

- HTML5 & CSS3
- JavaScript (ES6+)
- Bootstrap 5.3.0
- AOS 2.3.4 (Animate On Scroll)
- Font Awesome 6.4.0
- Custom Fonts (Proxima Nova)
- GSAP for animations

## Setup Instructions

1. Clone the repository:
```bash
git clone git@github.com:Gigarev/chipr-league-microsite.git
cd chipr-league-microsite
```

2. Serve the directory using any static file server. For example:
```bash
npx http-server
```

The site will be available at `http://localhost:8080`
